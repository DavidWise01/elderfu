RQT-091 · Hodge Caliper: Codimension 2

Mathematical model: X = CP² × CP² (complex dimension 4). Cohomology H*(X;Q)=Q[a,b]/(a³,b³), with deg(a)=deg(b)=2. We ask whether an unknown rational Hodge class alpha ∈ H⁴(X;Q), expressed in a²,ab,b², has a valid codimension-2 algebraic-cycle reconstruction. This is a known positive case, not the general conjecture.
  
The caliper sees only intersection measurements (∫alpha·a², ∫alpha·ab, ∫alpha·b²)=(r,q,p). It reconstructs alpha and checks that p({point}×CP²)+q(CP¹×CP¹)+r(CP²×{point}) has the required cohomology class, with generic projective lines/points understood.
All nonzero H⁴ classes here have Hodge type (2,2), because this product's even cohomology is generated by algebraic divisor classes. A successful test cannot address arbitrary smooth projective fourfolds. This is an exact symbolic pairing computation, not a numerical gravity simulation.
