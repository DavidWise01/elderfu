# RQT-079 — Constructive Hodge-class benchmark with {{i}} B/T zipper

## Hodge class (simple explanation)
For a smooth complex projective variety, a rational Hodge class is a rational cohomology class of Hodge type (p,p). The Hodge Conjecture asks whether each such class is a rational linear combination of classes of algebraic cycles.

## Full ASCII
```text
|||| {{i :: RQT-079 :: HODGE TEST}} ||||
    X = CP1 x CP1
         |
    alpha = 2a + 3b
         |
      PRIM a,b
         |
    B -> T -> B -> T
         |
       REVERSE
         |
     same class
  TL: B      TR: {{n²-1}} odd
       {{n}} center
  BL: T      BR: {{n²}} even
  n = 2,4,6,8
|||| NO QUORUM :: PRESERVE :: cubit ||||
```

## Independently executed exact rational tests
- PASS: On CP1 x CP1, class alpha=2a+3b equals the class of the explicit algebraic cycle 2 vertical-curve classes plus 3 horizontal-curve classes; a²=b²=0, ab is the point class.
- PASS: On CP2 x CP2, beta=a²+2ab+3b² is a sum of products of algebraic divisor classes, so it is represented by algebraic cycles; a³=b³=0.
- PASS: n=2,4,6,8: top=n²-1 odd, bottom=n² even; B/T/B/T wrapping round-trip preserves exact payload.
- LIMIT: generators and algebraic cycles are known in advance; no unknown class is solved, so this is not a proof of the general Hodge conjecture.
- All calculations are elementary exact symbolic identities, not a claim of physical topology.
